# Wallpapers

These are the two geometric wallpaper variants I use:

- `flake.jpg` — the dark blue/purple version from my Acer setup.
- `flake-gray.png` — the gray version, added from this laptop.

To use it, download the file, right-click it in File Explorer, and choose **Set as desktop background**. Or go to **Settings → Personalization → Background**, choose **Picture**, and browse to it.

They are here because they are part of the look, but neither is required for any of the configs to work.
