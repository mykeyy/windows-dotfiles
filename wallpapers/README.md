# Wallpapers

`flake.jpg` is the dark geometric wallpaper from my Acer setup at the time this repo was exported.

To use it, download the file, right-click it in File Explorer, and choose **Set as desktop background**. Or go to **Settings → Personalization → Background**, choose **Picture**, and browse to it.

It is here because it is part of the look, but it is not required for any of the configs to work.
